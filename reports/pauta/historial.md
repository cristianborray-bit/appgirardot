## Cómo leer esta tabla

- **Clics enlace**: clics reales que llegaron a la web (no incluye clics basura). Es la base del embudo, no los "clics totales".
- **Chats (IniciaChat)**: personas que de verdad abrieron el chat calificador. Es el resultado que la campaña optimiza.
- **Leads / Correos**: prospectos capturados en la base de datos y correos automáticos enviados. Si hay chats pero 0 leads, el bot informa pero no captura.
- La meta es ver estas tres últimas columnas **subir** con el tiempo sin que el costo se dispare.
